<p align="center">
RavenArm
</p>

<p>
The Raven Arm Project connects a Raven II surgical tool to an OpenArm v1.0 robotics platform using a 3D printed enclosure and an OpenRB-150 controller using MicroROS to control 4x Dynamixel servos that allow for force data to be collected from the tool tip, enabling force feedback to a sufficently capable spatial controller.
</p>
